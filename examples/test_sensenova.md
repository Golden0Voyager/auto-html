# SenseNova U1 创意工作台

SenseNova U1 是商汤科技推出的原生统一多模态模型，基于 NEO-unify 架构，在单一模型中实现了理解、推理和生成的统一。

## 核心架构

NEO-unify 架构消除了传统的 Visual Encoder 和 VAE，实现了语言和视觉信息的端到端统一。模型直接在像素级别处理图像，无需中间压缩步骤。

主要特点包括：
- 端到端的语言和视觉信息统一处理
- 保持语义丰富性的同时维持像素级视觉保真度
- 通过原生 MoT（Mixture-of-Transformers）高效跨模态推理

## 能力展示

SenseNova U1 在多个基准测试中取得了开源模型的最佳成绩：

| 能力维度 | 表现 |
|---------|------|
| 视觉理解 | 超越多数专用理解模型 |
| 图像生成 | 信息图、海报、漫画质量领先 |
| 图像编辑 | 换装、风格迁移、文字替换 |
| 图文交错 | 连续图文创作，单模型输出 |

## 应用场景

1. **内容创作**：自动生成配图、封面、信息图
2. **电商运营**：产品图编辑、营销海报生成
3. **教育培训**：图文教程、知识图解
4. **设计辅助**：草图精修、风格迁移
